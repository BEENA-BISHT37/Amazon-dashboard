# 📊 Amazon Sales Dashboard (Power BI)

This project is an interactive **Amazon Dashboard** created using **Power BI** to visualize and analyze key business metrics such as sales performance, orders and product trends.  
It helps users and stakeholders make data-driven decisions based on real-time insights.

---

## 🔧 Features

- 📦 Overview of total orders, sales, and revenue
- 🗓️ Filter by date range, category, and region
- 📈 Visualizations of top-selling products and peak sales times
- 📊 Graphs for profit margin, return rates, and customer trends
- 📍 Regional sales distribution using maps
- 📱 Responsive Power BI dashboard layout (works well on all screens)

---

## 🛠️ Tools & Technologies

- **Power BI** – for creating dashboards and reports
- **Excel / CSV** – as the source data
- **DAX** – for calculated columns and measures
- **Power Query Editor** – for data cleaning and transformation
